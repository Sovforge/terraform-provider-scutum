# terraform-provider-scutum

Terraform provider for [Scutum](https://github.com/Sovforge/Scutum), a self-hosted WireGuard mesh orchestration platform. Manage nodes, node groups, hub federation, webhooks, and users as infrastructure-as-code.

Built with the [Terraform Plugin Framework](https://developer.hashicorp.com/terraform/plugin/framework) v1.19.

## Resources

- `scutum_node` — register hub/remote WireGuard nodes
- `scutum_group` — node groups with member management
- `scutum_federation_peer` — link federated hub meshes
- `scutum_webhook` — webhook endpoint subscriptions
- `scutum_user` — user accounts and role assignment

See [`docs/`](./docs) for full schema reference (generated by [tfplugindocs](https://github.com/hashicorp/terraform-plugin-docs) — run `make docs` to regenerate after schema changes).

## Usage

```hcl
terraform {
  required_providers {
    scutum = {
      source  = "Sovforge/scutum"
      version = "~> 1.0"
    }
  }
}

provider "scutum" {
  endpoint = "https://scutum.example.com"
  api_key  = var.scutum_api_key # or set SCUTUM_API_KEY env var
}

resource "scutum_node" "edge_eu_west" {
  name       = "edge-eu-west-1"
  type       = "remote"
  address    = "10.100.0.10/32"
  public_key = "Jk5Hf3zXqTvP2LmN9sKdWbYcEuRoAiQeGhVwMnBxOp0="
}
```

More examples in [`examples/`](./examples).

## Releasing

Releases are built by [GoReleaser](https://goreleaser.com) via [`.github/workflows/release.yml`](.github/workflows/release.yml), triggered by pushing a `v*` tag (e.g. `v1.0.0`). Before the first tag push, the repo needs:

1. **A GPG signing key.** The Terraform Registry requires every release artifact to be signed. Generate one (`gpg --full-generate-key`), then add its **armored private key** as the `GPG_PRIVATE_KEY` repo secret and its passphrase as `PASSPHRASE`.
2. **The public key registered with the Terraform Registry** once you publish the provider there (registry.terraform.io → Publish → Provider → add your GPG public key under your account's signing keys).
3. **Registry listing** (optional, only needed for the provider to be installable as `source = "Sovforge/scutum"` directly): sign in to registry.terraform.io with the `Sovforge` GitHub org, and add this repo as a new provider. The registry re-scans GitHub releases automatically after that — no separate publish step per release.

Without registry listing, the built release artifacts (zips + `SHA256SUMS` + signature + manifest, all attached to the GitHub Release) still work as a [filesystem or network mirror](https://developer.hashicorp.com/terraform/cli/config/config-file#provider-installation) source.
